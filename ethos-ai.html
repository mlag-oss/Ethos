Configurar Login com Google

⚠ Arquivo aberto direto do computador
O Google bloqueia login OAuth em arquivos locais (file://). Você precisa servir o arquivo via servidor antes de continuar. Veja o Passo 1 abaixo.

PASSO 1 — Servir o arquivo (escolha uma opção):

A) Localmente — abra o Terminal e rode:
cd ~/Ethos && python3 -m http.server 8080 Depois acesse: http://localhost:8080/ethos-ai.html

B) GitHub Pages (recomendado) — gratuito e permanente:
Crie um repositório no github.com, suba o arquivo e ative o GitHub Pages em Settings → Pages.

PASSO 2 — Criar OAuth Client ID (gratuito):

  1. Acesse console.cloud.google.com/apis/credentials
  2. Clique em "Criar credenciais" → "ID do cliente OAuth 2.0"
  3. Tipo: Aplicativo da Web
  4. Em "Origens JavaScript autorizadas" adicione a URL do Passo 1
  5. Clique em Criar e copie o Client ID
